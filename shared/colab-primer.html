Google Colab: A Quick Primer

Everything you need to know before you open your first notebook — no prior experience assumed.

What Colab Is

Google Colab runs Python in your browser. There is nothing to install and nothing to configure — you open a link, sign in with your Elon Google account, and the code runs on Google's computers, not yours. Every notebook you're assigned already has the libraries it needs.

Before You Touch Anything

1
Open the notebook link and sign in
Click the “Open in Colab” link on your assignment page. If you're not already signed in, use your Elon student email (yourname@elon.edu) — not a personal Gmail account, or you'll lose access to anything shared with your Elon account later.
2
Save your own copy immediately — before you run or edit anything
This is the step people skip and regret. The notebook you opened isn't saved anywhere tied to your account yet — it's a read-only view of someone else's file. Go to File → Save a copy in Drive right away. A new tab opens with your own editable copy in your Google Drive. Do all your work in that tab, not the original.

How Notebooks Work

3
Two kinds of cells
A notebook is a stack of boxes called cells. Gray boxes are code cells — Python you run. Plain-text boxes are markdown cells — instructions and explanations, not code. You'll run the code cells and, in some notebooks, edit a markdown cell yourself to type an answer.
4
Running a cell
Click a code cell, then press Shift + Enter (or click the ▶ play button on its left edge). Wait for it to finish — a spinning circle means it's still running — before moving to the next one.
5
Run cells top to bottom, in order
Later cells depend on earlier ones — a cell that uses a variable named df only works if you already ran the earlier cell that created df. Skipping around or running things out of order is the single most common source of confusing errors.
6
Reading what happened
A small number like [3] next to a cell means it ran successfully, in that order. A red block of text underneath a cell means it errored. If things look broken or out of order, don't hunt for the one bad cell — go to Runtime → Restart and run all and let every cell run fresh from the top.
7
Typing into a markdown cell
Double-click a markdown cell to edit it (it turns into a plain text box). Type your answer, then press Shift + Enter to render it back to formatted text.

Turning In Your Work

8
Share your copy and submit the link
In your own copy (from Step 2), click Share in the top-right corner, change the access setting to “Anyone with the link” → Viewer, then copy the link. Paste that link into your Canvas submission. Don't submit the original link from Step 1 — that one isn't your copy and won't show your work.

If Something Goes Wrong

Every notebook you're assigned already has its libraries installed — you should never need to install anything yourself. If a cell errors, the fix is almost always Runtime → Restart and run all. If that doesn't fix it, come to office hours with the notebook open; it's much faster to debug together than to describe over email.
